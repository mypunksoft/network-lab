# Guacamole

На [[Raspberry Pi 5]] работают три контейнера: `guacamole` (веб-интерфейс), `guacd` (шлюз удалённых протоколов) и `guac-db` (MariaDB 10.11). Веб-интерфейс опубликован на TCP `8090` всех интерфейсов Raspberry Pi и доступен через [[Caddy]] по внутреннему имени `ssh.example.test`. Локальная проверка прокси дала HTTP `200`. [[NETWORK|Карта сети]]

Порты MariaDB `3306` и `guacd` `4822` остаются внутри Docker-сети `guacamole_default`; на интерфейсах хоста не опубликованы. Образ веб-контейнера — `guacamole/guacamole:1.6.0`.
