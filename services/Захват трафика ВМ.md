# Выборочный захват трафика ВМ

Проверено 12 октября 2026 года на [[Server2]]. На хосте установлен `/usr/local/libexec/vmcap-run` и шаблон systemd `vmcap@.service`. Захват **не запускается автоматически**: пользователь включает его на время конкретного теста. Допустимые имена ВМ: `arch`, `debian`, `windows10`. В домашнем каталоге пользователя `portfolio` есть исполняемый `/home/portfolio/start-vmcap.sh` для запуска записи с выбором ВМ.

```bash
~/start-vmcap.sh             # выбрать ВМ из меню
~/start-vmcap.sh windows10   # сразу выбрать Windows
```

Скрипт требует, чтобы ВМ уже работала, и запросит пароль `sudo` для запуска службы. При выключенной ВМ он завершится без запуска записи.

```bash
sudo systemctl start vmcap@windows10
systemctl status vmcap@windows10
sudo systemctl stop vmcap@windows10
```

Для Arch или Debian заменить `windows10` на имя ВМ. Служба запускается только если выбранная ВМ уже работает; при её выключении захват останавливается сам. Одновременно может работать только один захват. Необходимо включить захват **до** запуска проверяемого файла.

Пакеты читаются с физического `enp2s0` до NAT на [[AXGATE 80D]] и фильтруются по MAC выбранной ВМ, полученному из libvirt. Такой фильтр захватывает трафик в обоих направлениях, включая ARP, DNS и IPv6, даже если IP ВМ изменился. Файлы PCAP создаются в `/mnt/disk1/vm-pcaps/<ВМ>/<UTC-время>/` на диске `/dev/sdd1` объёмом 4 ТБ, вне публичного каталога `/mnt/disk1/file_server`. Каталоги имеют права `0700` и принадлежат пользователю `portfolio`.

`tcpdump -C 100 -W 100` ограничивает один сеанс примерно 10 ГБ с перезаписью старых файлов **внутри этого сеанса**. Перед новым сеансом скрипт проверяет общий объём архива и отказывает, если он превышает 90 ГБ: так суммарный объём остаётся примерно в пределах 100 ГБ. Старые сеансы автоматически не удаляются. Служба не включена в автозагрузку.

12 октября 2026 года тестовый сеанс Arch записал 39 пакетов без потерь ядра. В PCAP видны запросы Arch к `1.1.1.1:53` и ответы. После выключения Arch служба перешла в `inactive`. Содержимое HTTPS без отдельной расшифровки в PCAP не видно.
