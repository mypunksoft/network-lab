# Home Assistant

Контейнер `homeassistant` на [[Raspberry Pi 5]] использует режим Docker `host` и слушает TCP `8123` на сетевых интерфейсах. Через [[Caddy]] на [[Server1 Banana Pi]] доступен по внутреннему имени `ha.example.test`; локальная проверка прокси дала HTTP `200`. MQTT-брокер Mosquitto работает на том же Raspberry Pi. [[NETWORK|Карта сети]]

Связанный процесс [[go2rtc]] слушает TCP `18554` только на localhost и TCP `18555` на сетевых интерфейсах. Home Assistant также использует сетевые механизмы обнаружения устройств; перечень интеграций не считывался.
