# WireGuard и wanroute

На [[OpenWrt]] интерфейс `wg` активен и служит основным маршрутом. Вторая таблица `wanroute` имеет default route через WAN-шлюз `192.0.2.1`, чтобы часть трафика выходила без VPN. [[NETWORK|Карта сети]]

Правила `ip rule` направляют через `wanroute` исходящий трафик [[Server2]] (`203.0.113.0/24`), PS4 (`198.18.40.10`) и [[FRP]] после SNAT на [[AXGATE 80D]] (`198.51.100.2 → 203.0.113.10`). Для ответов Server2 в LAN действует более приоритетный возврат в основную таблицу.

Для возврата ответов к PS4 в основной таблице OpenWrt настроен постоянный маршрут `198.18.40.0/24` через AXGATE `198.51.100.2` (`lan4`). Без него ответы уходили через `wg`, и PS4 сообщала о таймауте DNS. После исправления AXGATE фиксирует ответы DNS и двусторонние HTTPS-сеансы; пользователь подтвердил, что PS4 работает.
