# SSH

Удалённый административный доступ. [[NETWORK|Карта сети]]

| Узел | Реализация и порт | Доступ |
| --- | --- | --- |
| [[OpenWrt]] | Dropbear, TCP `22` | Вход root по паролю проверен. |
| [[Server1 Banana Pi]] | OpenSSH, TCP `22` | Вход пользователя `pi` по паролю проверен. |
| [[Server2]] | OpenSSH, TCP `22` | Вход по ключу проверен; по описанию [[AXGATE 80D]] пропускает SSH только с `192.0.2.167`. |
| [[Eltex NV-501-WAC]] | Android `sshd`, TCP `22` | Вход по ключу проверен; ограничение источника задано на AXGATE по описанию. |
| [[VPS]] | OpenSSH, TCP `22` и `654` | Вход по ключу проверен. |

Пароли и приватные ключи в хранилище не записаны. Наличие слушающего порта не заменяет проверку политики межсетевого экрана.
