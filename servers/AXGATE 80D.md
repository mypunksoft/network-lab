## Границы доступа и политики

Условия источника и назначения ниже взяты из описания сети. CLI подтвердил существование 14 политик безопасности, их направления, действия и приоритеты, но не показал все поля сопоставления объектов.

| Источник → назначение | Трафик | Действие по описанию | Проверка |
| --- | --- | --- | --- |
| Ноутбук `192.0.2.167` → [[Server2]] `203.0.113.10` | TCP `22` | PASS | На CLI есть untrust → trust PASS с приоритетом 5. |
| Прочие клиенты LAN → trust | TCP `22` | DROP | На CLI есть untrust → trust DROP с приоритетом 10. |
| LAN → trust | Остальной разрешённый трафик | PASS | На CLI есть untrust → trust PASS с приоритетом 20. |
| Ноутбук `192.0.2.167` → [[Eltex NV-501-WAC]] `198.18.30.10` | TCP `22` | PASS | На CLI есть правила untrust → print PASS и DROP. |
| Прочий LAN → print | Любой | DROP | Условия взяты из описания. |
| Eltex → [[VPS]] `203.0.113.10` | [[FRP]], TCP `7000` | PASS | Print → untrust PASS активен и имел попадания при проверке. |
| Test → trust и домашняя LAN | Любой | DROP | Test → trust DROP активен; из Arch TCP к Server2 и домашним адресам не установился за 4 с. |
| Test → интернет | Разрешённый исходящий трафик | PASS + NAT | Правило NAT test → untrust есть; TCP к `1.1.1.1:443` из Arch установился. |
| Game → интернет | Сетевой тест PS4, затем блокируемые домены, затем прочий трафик | PASS → DROP → PASS | Три правила game → untrust с приоритетами 9, 10, 11 подтверждены. |

Из трёх NAT-правил AXGATE одно относится к print → untrust, одно к test → untrust и одно к trust → untrust. Для FRP по описанию print-сегмент SNAT-ится в `198.51.100.2`; это согласуется с правилом маршрутизации на [[OpenWrt]]. Отдельное NAT-правило для game при проверке не найдено. По сообщению пользователя, PS4 ранее работала с правилами AXGATE.

Повторная проверка 12 октября 2026 года: `test → trust` (ID 10) — `drop log`, активно; `test → untrust` (ID 9) — `drop log`, активно, счётчик 0; `test → untrust` (ID 11) — `pass log`, активно, счётчик 1888. С Arch не установились TCP-соединения к `203.0.113.10:22`, `192.0.2.1:22`, `192.0.2.152:443` и `198.18.30.10:22` (таймаут 4 с), интернет `1.1.1.1:443` доступен. Это проверка достижимости, а не полная ревизия всех условий политик. До настройки доступа к управлению из Arch был доступен CLI самого AXGATE на `198.18.20.1:2323`: межзонные политики не ограничивают доступ к службам на интерфейсе самого шлюза. Действия `pass log` и `drop log` уже включают журналирование; для просмотра пакетов доступна CLI-команда `tcpdump interface eth3 ...`.

Для лабораторного сегмента настроен и сохранён список разрешённых источников управления: `admin network ip 203.0.113.0/24`, `198.51.100.0/30`, `192.0.2.0/24`. Сеть test `198.18.20.0/24` в список не входит. После настройки из Arch TCP к CLI `198.18.20.1:2323` и веб-панели `198.18.20.1:17877` не установился за 4 секунды, а к `1.1.1.1:443` установился. Новый TCP-сеанс к CLI со стороны Server2 `203.0.113.10` устанавливается. Перед сохранением `show config-diff` содержал только эти три строки; после `write` различий между running и startup нет. Arch после теста выключена.

`PS4_BLOCK` по исходному описанию содержит `*.playstation.net`, `*.playstation.com`, `*.playstation.org`, `*.sonyentertainmentnetwork.com`, `*.ribob01.net`, `playstation.sony.akadns.net`. В CLI подтверждена последовательность трёх действующих game → untrust правил: PASS с приоритетом 9, DROP с приоритетом 10 и PASS с приоритетом 11. Первые два на момент проверки не имели попаданий; последнее имело 554 исторических попадания. Конкретные совпадения по доменам в CLI не считывались.

12 октября 2026 года PS4 с адресом `198.18.40.10` сообщала о таймауте DNS. AXGATE показывал исходящие запросы UDP/53 к `1.1.1.1` и `8.8.8.8` без ответов; трафик проходил по общему правилу game → untrust (приоритет 11). Причиной оказался отсутствовавший обратный маршрут на [[OpenWrt]]: ответы в `198.18.40.0/24` уходили через WireGuard. После добавления маршрута через `198.51.100.2` AXGATE увидел ответы DNS и двусторонние HTTPS-сеансы PS4. Пользователь подтвердил, что повторный тест PS4 работает.
